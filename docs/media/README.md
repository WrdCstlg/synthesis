## What playback preserves and what it adjusts

Each `.cast` file records the exact byte stream emitted by `synthesis` with measured timestamps. On SVG playback, [`render-cast-svg.mjs`](../../scripts/demo/render-cast-svg.mjs) adjusts timing only:

1. Pauses longer than 1 second are compressed to 1 second.
2. Output bursts taller than 24 terminal rows step one screen at a time (5 seconds per screen).
3. Lines wider than 100 columns wrap cleanly.

Viewers configured with `prefers-reduced-motion: reduce` render the final terminal screen statically without animation.

## Regenerating everything from live runs

```powershell
# Record all four scenes against a live Docker daemon and render all SVGs:
powershell -ExecutionPolicy Bypass -File scripts/demo/record-showcase.ps1

# Re-render terminal SVGs from existing .cast recordings (requires Node.js, not Docker):
powershell -ExecutionPolicy Bypass -File scripts/demo/record-showcase.ps1 -RenderOnly
```
